Each guide gets you one result in a few steps. There is no theory. Every guide ends with links to the pages that explain why it works.

- [Play an animation on a loop](01-play-an-animation-on-a-loop.md): get an animated FBX or glTF character moving in the scene
- [Switch between two animations](02-switch-between-two-animations.md): change what a character plays from a script
- [Spawn a prefab](03-spawn-a-prefab.md): create objects from a saved prefab, in the editor and from a script
- [Play a sound](04-play-a-sound.md): hear an audio clip in your game
- [Read player input](05-read-player-input.md): move or act from keys, mouse and gamepad
- [Show a button on screen](06-show-a-button-on-screen.md): add a clickable button to your game's screen
- [Make an agent walk to a point](07-make-an-agent-walk-to-a-point.md): bake a NavMesh and send a character to a goal
- [Add a particle effect](08-add-a-particle-effect.md): add a glowing effect and switch it on and off from a script
- [Load the next level](10-load-the-next-level.md): switch scenes when the player reaches a trigger
- [Do something after a delay](11-do-something-after-a-delay.md): wait a few seconds in a script without freezing the game
- [Float a boat on the ocean](20-float-a-boat-on-the-ocean.md): make a physics object bob on the waves
- [Make a glass material](30-make-a-glass-material.md): see-through glass with no custom shader
- [Make a character walk and run with a graph](40-make-a-character-walk-and-run-with-a-graph.md): blend idle, walk and run from a Speed value
- [Add a hit reaction](41-add-a-hit-reaction-with-an-any-state-transition.md): interrupt any animation with a one-shot hit
- [Make an object fall and bounce](50-make-an-object-fall-and-bounce.md): drop a sphere onto a floor with no code
- [Detect when the player enters an area](51-detect-when-the-player-enters-an-area.md): react to a trigger volume from a script
