Prowl is an open-source C# game engine with a complete editor. These pages take you from a fresh install to a running game.

- [Installation](01-installation.md) covers the requirements and both ways to get Prowl.
- [Getting started with the editor](02-editor.md) builds, plays and ships a small scene.
- [Getting started with the runtime](03-runtime.md) builds a game entirely in code, with no editor.
- [Things to know first](04-things-to-know.md) covers the rules that trip people up most.
