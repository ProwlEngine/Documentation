---
title: In-game UI
description: Put menus, buttons, text and HUDs on the screen of your game.
---

In-game UI is everything the player sees on top of, or inside, the game world: menus, a health bar, a score. Prowl has two ways to build it. You can build it from GameObjects with a **GameCanvas**, or you can draw it from code with Paper, Prowl's immediate-mode UI.

Start with the first page. It covers both.

- [Getting started with UI](01-getting-started-with-ui.md): canvases, rect transforms, text, images and buttons
- [Drawing UI with Paper](02-drawing-ui-with-paper.md): draw a HUD from code in `OnGui`
